# Product Requirements Document - SIMS v2.2

## 1. Project Objective
Deliver a production-ready, offline-first Desktop ERP for Sudharm Infotech.

## 2. Launch Scope (Day-1 Must-Haves)
- **Core:** Secure login, fail-closed router, persistent dashboard shell.
- **Students:** Add, View, and Edit student profiles.
- **Courses/Batches:** Create/edit courses, assign students to batches.
- **Finance Engine:** Record fee payments, generate immutable sequential receipt numbers, track pending dues.
- **Reports:** Daily/monthly collection, active students list.
- **Settings:** Manual & automatic SQLite backups, Institute profile.

## 3. Out of Scope (Do NOT build for v2.2 Launch)
- Attendance tracking.
- WhatsApp/SMS API integration.
- Multiple User Roles (Launch is strictly Single Administrator).
- Complex OCR/Document scanning.
