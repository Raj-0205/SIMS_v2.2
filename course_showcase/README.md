# 🎓 MKCL Career Course Showcase & Presentation Application

An interactive, colorful, and smoothly animated presentation suite designed for **MKCL Authorized Learning Centers** to counsel and introduce courses to prospective **Students and their Parents**.

---

## 🌟 Key Features

1. **27 Authentic MKCL Courses Across 8 Career Tracks**:
   - **Flagship**: MS-CIT (AI Literacy, 144 Hours, MSBTE Certified, 1.5+ Crore Learners)
   - **Financial Accounting**: Tally Prime with GST, Advanced Excel, Advanced Financial & Taxation
   - **Digital Designing & Creative Arts**: Graphic Designing, AutoCAD, 3D Modelling, 3D Animation, Video Editing Techniques, DTP (Adobe & CorelDRAW), Content Illustration
   - **Software Development**: Python with AI/ML, C & C++ Programming, Java, Web Designing, PHP & MySQL
   - **New Collar & Emerging Tech**: AI-ML Basics, Data Science, Digital Freelancing ("Work Locally, Earn Globally")
   - **IT Hardware, Networking & Cyber Security**: Cyber Security, Desktop Support, Network Support, Security Support
   - **Back Office & Cloud**: Data Entry & Data Management, Google Workspace Expert, Office Assistance
   - **Front Office & Soft Skills**: English Communication, Soft Skills, KLiC IT

2. **Dual Counselor Presentation Modes**:
   - **👨‍👩‍👦 Parent Mode**: Emphasizes government job eligibility (MSBTE/MKCL), career stability, job designations, salary scope, and talking points addressing parent hesitations.
   - **🚀 Student Mode**: Focuses on exciting practical projects, hands-on capstone builds, modern AI tools (ChatGPT, Midjourney), and digital freelancing income.

3. **Slow & Impressive Cinematic Animations**:
   - Paced gracefully at 0.8s - 1.2s cubic-bezier transitions with gentle floating ambient glow meshes to keep presentations calm, polished, and executive.

4. **Interactive Counseling Tools**:
   - **Full-Screen Deep-Dive Course Intro**: Comprehensive syllabus explorer with search, tools grid, and eligibility info.
   - **📺 Fullscreen Projector / Presentation Deck**: Fullscreen slideshow with keyboard navigation (`◀` / `▶` / `Space`) for presenting across a desk monitor or TV screen.
   - **⚖️ Side-by-Side Course Comparison**: Compare up to 3 courses simultaneously.
   - **🎯 3-Step Course Finder Quiz**: Quick interactive recommendation wizard matching learner profile, goals, and duration.
   - **📄 Printable Student Admission Proposal**: Generates a professional branded proposal card with student name, chosen course, batch timing, and center seal for printing or saving to PDF.
   - **💬 Direct WhatsApp Inquiry Button**: One-click WhatsApp inquiry generator.

5. **100% Offline-First Architecture**:
   - All thumbnails, showcase banners, styles, and data are stored locally in `assets/images/`, `css/`, and `js/`.
   - Requires zero external database connections and zero modifications to SIMS core databases.

## 🚀 How to Run

### Method 1: One-Click Python Launcher (Recommended)
From the terminal or command line:
```bash
python3 /home/raj_28/SIMS_v2.2/course_showcase/launch_showcase.py
```
This automatically starts an offline server and launches your default web browser at `http://localhost:8080/index.html`.

### Method 2: Direct Browser Opening
Simply double-click or open `course_showcase/index.html` directly in Google Chrome, Microsoft Edge, Firefox, or Safari.
